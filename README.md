# shaira-portfolio

Portfolio of Maria Shaira Leigh A. Rabasto. Built with React, TypeScript and Vite.

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
Push to GitHub, then import the repo in Vercel (framework preset: Vite). Nothing else to configure.

## Edit content
All text, links and certificates live in `src/data.ts`. Images live in `public/images`.
